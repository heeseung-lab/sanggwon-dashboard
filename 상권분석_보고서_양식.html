2 상권 지도홀+배달 모드

경쟁점 위치·추정매출, 반경권역, 배달권역 — 카카오맵 실데이터로 자동 표시됩니다

⚙ API 키 설정 (평소엔 안 보여도 됨 — 키 교체가 필요할 때만 펼치기)

※ 이 파일에는 카카오 JS 키가 이미 저장되어 있어 매번 다시 입력할 필요 없습니다. 화면에는 점(•)으로 가려져 있고, 눈 아이콘을 누르면 잠깐 확인할 수 있습니다. (JS 키는 원래 브라우저에서 쓰도록 만들어진 키라 노출을 감안한 키입니다 — 서버용 REST API 키는 절대 이 파일에 넣지 마세요.)

※ 이 파일에는 "검색 API" 승인키가 이미 저장되어 있어 매번 다시 입력할 필요 없습니다 — 실제 검색까지 확인된 키입니다.

※ 이 키가 없어도 헤더 입력창에 주소를 직접 타이핑해서 "분석"을 누르는 방식은 그대로 동작합니다 — 이 키는 "동/도로명만 입력해도 목록에서 골라 선택"하는 검색에만 필요합니다.

※ 이 저장소는 Public이라 이 키는 파일(코드)에는 저장해두지 않았습니다 — 키를 입력하면 "반경 1km 내 음식업종 전체"(1번 지역개요)와 "인근 상업용 부동산 실거래가"(1번 지역개요) 두 수치를 모두 이 하나의 키로 실시간 조회합니다(공공데이터포털은 같은 계정 키를 여러 API에 공용으로 쓸 수 있습니다). 대신 이 브라우저의 로컬 저장소(localStorage)에 남겨두어, 한 번 입력하면 이 브라우저·이 컴퓨터에서는 새로고침해도 다시 입력할 필요 없습니다(다른 브라우저·기기·시크릿모드에서는 다시 입력 필요, 저장소 코드에는 절대 올라가지 않음). data.go.kr에서 받은 "Encoding" 값을 그대로 붙여넣어주세요.

※ 이 키도 Public 저장소라 파일(코드)에는 저장하지 않았습니다 — 입력하면 이 브라우저의 localStorage에만 남고, 아래 "배달 경쟁 등급" 패널에 소상공인365(소상공인시장진흥공단)의 배달분석 화면을 그대로 불러옵니다. 소상공인365에 정식으로 오픈API를 신청해 발급받은 certKey를 입력해주세요(신청: 소상공인365 → 이용안내 → 개방·활용 → 오픈 API 신청, 로그인 필요).

※ 위 배달분석 certKey와는 별도로 발급받아야 하는 키입니다(소상공인365는 기능별로 certKey가 나뉘어 있어, 배달분석용 키로는 이 위젯이 열리지 않습니다). 이 키도 Public 저장소라 파일(코드)에는 저장하지 않았습니다 — 입력하면 이 브라우저의 localStorage에만 남고, 아래 "지역·업종 평균 매출 추이" 패널에 소상공인365의 "점포당 매출액 추이" 화면을 그대로 불러옵니다. 이 데이터는 소상공인365 자체 업종 분류(247개) 기준 지역×업종 단위 평균 추정매출액이며, 실명 있는 개별 매장의 매출이 아닙니다.

※ 1번 지역개요의 "소규모 상가 평균 임대료(시도)" 타일은 한국부동산원 R-ONE 오픈API 데이터를 사용하지만, 브라우저가 reb.or.kr에 직접 보내는 요청은 그쪽 서버에서 차단되는 것이 확인되어(교차출처 요청만 골라 HTTP 503 응답) 이 화면에서 키를 직접 입력받지 않습니다. 대신 GitHub Actions가 주기적으로 서버 쪽에서 조회해 저장소 안의 정적 파일(data/reb_rent_by_sido.json)로 갱신해두면, 이 화면은 그 파일을 그대로 읽어 표시합니다. 이 통계는 시군구가 아니라 시도 단위 평균이며, 평균 임대면적(평수)은 이 통계에 항목 자체가 없어 제공하지 않습니다.

🛵 배달 경쟁 등급 — 소상공인365 (행정동·업종 단위)
📍 분석 지역: 분석 실행 후 표시 — 이 위젯은 자동으로 이동하지 않으니, 아래 "위치선택" 드롭다운에서 같은 지역을 직접 선택해주세요.
위 "⚙ API 키 설정"에서 소상공인365 certKey를 입력하면 표시됩니다

※ 소상공인365(소상공인시장진흥공단) 자체 화면을 그대로 불러온 것으로, 위젯 안에서 시도·시군구·업종을 직접 선택해 행정동 단위 배달 매출 등급(빨강=낮음~파랑=높음)을 확인할 수 있습니다. 이 대시보드의 분석 주소와 자동으로 연동되지는 않으며(외부 사이트라 위치 전달 불가), 특정 매장 실명에 결부된 수치가 아니라 동네·업종 단위 집계이므로 우리가 임의로 추정한 값이 아니라 소상공인365가 직접 제공하는 데이터입니다.

📊 지역·업종 평균 매출 추이 — 소상공인365 (점포당 매출액)
📍 분석 지역: 분석 실행 후 표시 — 이 위젯도 자동으로 이동하지 않으니, 아래 위젯 안에서 같은 지역과 브랜드 업종을 직접 선택해주세요.
위 "⚙ API 키 설정"에서 소상공인365 "점포당 매출액 추이" certKey를 입력하면 표시됩니다

※ 소상공인365가 제공하는 "점포당 매출액 추이"(지역×업종별 월평균 추정매출, 최대 13개월) 화면을 그대로 불러온 것입니다. 위젯 안에서 시도·시군구와 업종(247개 분류)을 직접 선택해 확인하며, 실명 있는 개별 경쟁매장의 매출이 아니라 그 지역·업종 전체의 평균 추정치이므로 우리가 임의로 추정한 값이 아니라 소상공인365가 직접 제공하는 참고용 데이터입니다(점포 면적·입점 위치 등에 따라 실제와 달라질 수 있음 — 소상공인365 자체 고지). 배달 경쟁 등급과 마찬가지로 이 대시보드의 분석 주소와 자동으로 연동되지는 않습니다.
